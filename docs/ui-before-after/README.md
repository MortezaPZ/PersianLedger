# قبل و بعد از بازطراحی UI

## قبل (نسخهٔ کامپایل‌شده ۰٫۵٫۰)
سایدبار سرمه‌ای `#1f3350`، دکمهٔ طلایی `#f0a441`، بدون تم تیره، بدون آیکون SVG، جداول بدون هاور مشخص.

## بعد (۰٫۶٫۰)
سیستم طراحی یکدست، Vazirmatn، RTL، تم روشن/تیره، آیکون SVG سایدبار، جداول راه‌راه با هاور، اعداد راست‌چین با جداکنندهٔ هزارگان.

فایل‌های `after-*.png` با `python scripts/capture_ui.py` گرفته می‌شوند.
