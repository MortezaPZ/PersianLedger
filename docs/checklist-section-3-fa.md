# بخش ۳ — چک‌لیست قبل از تحویل

نسخهٔ هدف: **۰٫۶٫۰**. تست upgrade با دیتابیس واقعی کارفرما نزدیک تحویل نهایی است، نه الان.

## الف) یازده مورد کارکردی (روی build پرتابل)

- [ ] ۱. دکمه‌های ComboBox / لیست در ثبت سند با یک کلیک باز می‌شوند.
- [ ] ۲. ذخیرهٔ سند شماره و ردیف‌ها را با هم ثبت می‌کند؛ در خطا هیچ‌کدام باقی نمی‌ماند.
- [ ] ۳. شرح در تراز آزمایشی / روزنامه / کاردکس دیده می‌شود.
- [ ] ۴. عرض ستون شرح با متن تنظیم می‌شود و از حدود ۳۰۰px بیشتر نمی‌شود.
- [ ] ۵. تفصیلی جدید کد پیشنهادی بر اساس گروه می‌گیرد (قابل ویرایش).
- [ ] ۶. گزارش تفصیلی عضو دو گروه: هر دو با هم، فقط گروه اول، فقط گروه دوم.
- [ ] ۷. مرور گروه ← کل ← معین ← تفصیلی با breadcrumb و بازگشت.
- [ ] ۸. سناریوی پروژه A با دادهٔ `--demo` با محاسبهٔ دستی می‌خواند (هر ارز جدا، بدون تسعیر).
- [ ] ۹. خروج: سؤال پشتیبان بله / خیر / انصراف.
- [ ] ۱۰. بازیابی بکاپ: برنامه دوباره باز می‌شود، درخت سرفصل‌ها می‌آید، پنجره داخل مانیتور می‌ماند.
- [ ] ۱۱. گزارش‌ها سوییچ «مانده قبل از بازه» دارند.
